# Needle Drop

Hear ten seconds of a record from anywhere in the world, 1930 to now. Pin where it was made and
tune the dial to the year. Ten records a round, up to 10,000 points.

Play: https://lightpollutioncurseforge-a11y.github.io/needle-drop/

Clips are Apple Music previews, and every record links to the full track on Apple Music.
A private, non-commercial game for friends.
